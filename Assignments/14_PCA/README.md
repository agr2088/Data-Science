# PCA and Clustering Analysis

This folder contains instructor-evaluated assignments focused on
dimensionality reduction using Principal Component Analysis (PCA)
and unsupervised learning through clustering techniques.

## Files Included
- **Assignment_14.ipynb**  
  Python implementation including:
  - Understanding the dataset and feature space
  - Data preprocessing and feature scaling
  - Applying PCA for dimensionality reduction
  - Analyzing explained variance and selecting components
  - Visualizing data in reduced dimensions
  - Applying clustering algorithms on original and PCA-transformed data
  - Comparing clustering results before and after PCA

## Skills Demonstrated
- Principal Component Analysis (PCA)
- Dimensionality reduction
- Unsupervised learning and clustering
- Feature scaling and preprocessing
- Visualization of high-dimensional data
- Comparative analysis of clustering results
