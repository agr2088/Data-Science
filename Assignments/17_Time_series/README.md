# Time Series Analysis and Forecasting

This folder contains instructor-evaluated assignments focused on
analyzing time-dependent data and building forecasting models
to predict future values based on historical trends.

## Files Included
- **Assignment_17.ipynb**  
  Python implementation including:
  - Loading and visualizing time series data
  - Checking stationarity of the series
  - Applying differencing techniques
  - Building ARIMA/SARIMA models
  - Model diagnostics and residual analysis
  - Forecasting future values
  - Evaluating forecast accuracy using performance metrics

## Skills Demonstrated
- Time series analysis
- Stationarity testing and differencing
- ARIMA/SARIMA modeling
- Forecasting techniques
- Model diagnostics and residual analysis
- Performance evaluation (MAE, RMSE)
