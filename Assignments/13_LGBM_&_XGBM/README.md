# LGBM & XGBoost – Titanic Dataset (Comparative Classification Analysis)

This folder contains instructor-evaluated assignments focused on
comparing the performance of LightGBM (LGBM) and XGBoost (XGBM)
models for survival prediction on the Titanic dataset.

## Files Included
- **Assignment_13.ipynb**  
  Python implementation including:
  - Understanding the Titanic dataset and target variable
  - Exploratory data analysis and feature engineering
  - Handling missing values and categorical encoding
  - Feature scaling and data preparation
  - Building LightGBM and XGBoost classification models
  - Hyperparameter tuning and cross-validation
  - Comparative evaluation of model performance
  - Analysis using accuracy, ROC-AUC, and classification metrics

## Skills Demonstrated
- Gradient boosting techniques (LightGBM, XGBoost)
- Comparative model analysis
- Feature engineering and preprocessing
- Hyperparameter tuning and cross-validation
- Model evaluation using ROC-AUC and classification metrics
- Applied ensemble learning for classification
