# Natural Language Processing (NLP)

This folder contains instructor-evaluated assignments focused on
processing and analyzing textual data using Natural Language Processing
techniques for classification or sentiment analysis tasks.

## Files Included
- **Assignment_19.ipynb**  
  Python implementation including:
  - Text data preprocessing (tokenization, stopword removal, cleaning)
  - Converting text into numerical representations (Bag-of-Words / TF-IDF)
  - Feature extraction from textual data
  - Building and training NLP classification models
  - Evaluating model performance using classification metrics
  - Interpreting results and improving text-based predictions

## Skills Demonstrated
- Natural Language Processing (NLP)
- Text preprocessing and cleaning
- Feature extraction (BoW, TF-IDF)
- Text classification modeling
- Model evaluation and interpretation
- Applied machine learning for textual data
