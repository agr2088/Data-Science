# Data Science Assignments

This folder contains instructor-evaluated assignments completed as part of my structured Data Science training. The work reflects progressive learning from programming fundamentals to advanced machine learning and deep learning concepts, with strong emphasis on implementation, analysis, and model evaluation.

## Contents

- **python_basics/**  
  Foundations of Python programming including control flow, functions, loops, and structured problem-solving.

- **numpy_pandas/**  
  Data manipulation and transformation using NumPy and Pandas, including structured data handling and preprocessing techniques.

- **data_visualization/**  
  Exploratory data analysis and visualization using Matplotlib and Seaborn to uncover patterns and insights.

- **statistics/**  
  Descriptive and inferential statistics including probability concepts, confidence intervals, and hypothesis testing.

- **machine_learning/**  
  Supervised and unsupervised learning implementations covering model training, evaluation, hyperparameter tuning, and comparative analysis.

- **deep_learning_intro/**  
  Foundational deep learning concepts including Artificial Neural Networks (ANN), Recurrent Neural Networks (RNN), and introductory NLP techniques.

## Objective

These assignments demonstrate:
- Strong analytical foundations  
- Ability to translate statistical theory into practical implementation  
- Structured machine learning workflow development  
- Model evaluation and interpretability  
- Clean and modular coding practices  

This section serves as the foundational layer of my Data Science portfolio and supports the transition toward real-world, project-driven applications.
