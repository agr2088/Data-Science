# 📂 Datasets

## Overview

This directory contains curated datasets used across my Data Science, Machine Learning, and MLOps projects.

The datasets included here support experimentation, academic assignments, end-to-end model development, and portfolio projects.

---

## 🎯 Objective

The primary goals of maintaining this dataset repository are:

- Ensure reproducibility of experiments
- Maintain organized data assets for multiple projects
- Support EDA, feature engineering, and model training workflows
- Provide structured data access for scalable ML pipelines

---

## 🌐 Data Sources

Datasets have been collected from reputable and publicly accessible platforms, including:

- Kaggle
- Open-data repositories
- Academic and research datasets
- Learning Management System (LMS) portal resources
- Project-specific datasets from industry-style case studies

All dataset ownership and rights remain with their original authors and platforms.

---

## 📊 Dataset Types

This repository may include:

- Structured data (CSV, XLSX)
- Regression datasets
- Classification datasets
- Time-series datasets
- NLP datasets
- Experimental datasets for academic exercises

---

## ⚠️ Usage & Compliance

- Datasets are used strictly for educational, research, and portfolio purposes.
- Sensitive or licensed datasets are not redistributed in violation of platform policies.
- Large datasets exceeding GitHub size limits are excluded and referenced via external links where applicable.
- For reproducibility, original dataset source links are documented in the respective project README files.

---

## 🔄 Versioning Strategy

- Raw datasets are preserved where possible.
- Processed datasets are stored separately within project directories.
- Data transformations and feature engineering steps are reproducible via notebooks or pipeline scripts.
