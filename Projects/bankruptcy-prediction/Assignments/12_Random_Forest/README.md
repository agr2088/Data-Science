# Random Forest Classification – Glass Dataset

This folder contains instructor-evaluated assignments focused on
building and evaluating a Random Forest classification model to
predict glass types based on their chemical composition.

## Files Included
- **Assignment_12.ipynb**  
  Python implementation including:
  - Understanding the glass dataset and target classes
  - Data preprocessing and feature selection
  - Handling class imbalance using class weights
  - Splitting data into training and testing sets
  - Building a Random Forest classifier
  - Applying bagging and ensemble learning concepts
  - Evaluating model performance using classification metrics
  - Analyzing feature importance

## Skills Demonstrated
- Random Forest classification
- Ensemble learning (bagging)
- Handling class imbalance
- Feature importance analysis
- Model evaluation and interpretation
- Applied machine learning using scikit-learn
