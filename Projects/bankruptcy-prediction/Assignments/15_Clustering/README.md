# Clustering Analysis

This folder contains instructor-evaluated assignments focused on
unsupervised learning using clustering algorithms to identify
patterns and groupings within the data.

## Files Included
- **Assignment_15.ipynb**  
  Python implementation including:
  - Understanding the dataset and feature space
  - Data preprocessing and feature scaling
  - Applying K-Means clustering
  - Applying Hierarchical clustering
  - Applying DBSCAN clustering
  - Visualizing cluster formations
  - Evaluating clustering performance using silhouette score
  - Interpreting and comparing clustering results

## Skills Demonstrated
- Unsupervised learning
- K-Means, Hierarchical, and DBSCAN clustering
- Feature scaling and preprocessing
- Cluster evaluation using silhouette score
- Visualization and interpretation of clusters
- Comparative analysis of clustering techniques
