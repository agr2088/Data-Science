# Recommendation System – Cosine Similarity Based Model

This folder contains instructor-evaluated assignments focused on
building a recommendation system using similarity-based techniques
to suggest relevant items to users.

## Files Included
- **Assignment_16.ipynb**  
  Python implementation including:
  - Understanding the recommendation problem
  - Data preprocessing and feature selection
  - Creating feature matrices for similarity computation
  - Applying cosine similarity for item-based recommendations
  - Building a recommendation function
  - Filtering and ranking top-N recommendations
  - Evaluating recommendation outputs

## Skills Demonstrated
- Recommendation system design
- Cosine similarity implementation
- Feature engineering for recommender systems
- Similarity-based modeling
- Ranking and filtering techniques
- Applied machine learning using Python
