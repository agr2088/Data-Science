# Decision Tree Classification – Heart Disease Dataset

This folder contains instructor-evaluated assignments focused on
building and evaluating a Decision Tree classifier to predict
the presence of heart disease using clinical and patient-related data.

## Files Included
- **Assignment_11.ipynb**  
  Python implementation including:
  - Understanding the heart disease dataset and target variable
  - Data preprocessing and feature selection
  - Handling missing values and encoding features
  - Splitting data into training and testing sets
  - Building a Decision Tree classification model
  - Visualizing and interpreting the decision tree
  - Evaluating model performance using classification metrics

## Skills Demonstrated
- Decision Tree classification
- Supervised learning
- Feature preprocessing
- Model interpretability
- Model evaluation (accuracy, confusion matrix, classification report)
- Applied machine learning using scikit-learn
