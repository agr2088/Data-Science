# Recurrent Neural Network (RNN)

This folder contains instructor-evaluated assignments focused on
building and evaluating Recurrent Neural Network (RNN) models
for sequential or time-dependent data.

## Files Included
- **20_RNN.ipynb**  
  Python implementation including:
  - Understanding sequential data and problem formulation
  - Data preprocessing and sequence preparation
  - Building an RNN model using TensorFlow/Keras
  - Selecting appropriate activation functions
  - Training and validating the RNN model
  - Evaluating performance using relevant metrics
  - Analyzing model learning behavior

## Skills Demonstrated
- Recurrent Neural Networks (RNN)
- Sequential data modeling
- Deep learning using TensorFlow/Keras
- Sequence preparation and preprocessing
- Model training and evaluation
- Understanding vanishing gradient challenges
